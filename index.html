01 // Tools

Snapshot, diff, catch takeovers.

MIT licensed. Read the source before you point any of it at your own perimeter.

HostageLVX
Takeover Engine

Dangling DNS and subdomain takeover detection in Go. 81 CNAME fingerprints across 21 providers, each with its own takeover signature, so a CNAME at a live bucket is not reported as a finding.

$ go install github.com/leviathan-offsec/HostageLVX@latest
Repository → MIT Go | CLI
surfacediff
Surface Diffing

Content-addressed snapshots of your perimeter, diffed field by field. Takes recon output on stdin, exits 1 on a delta. No daemon.

$ pip install git+https://github.com/leviathan-offsec/surfacediff.git
Repository → MIT Python | stdlib only
FenrirLVX
CMS Auditor

WordPress and CMS auditing in Go. Plugin fingerprinting and offline CVE correlation, with each verdict stating how much of the target the local database could actually speak to.

$ ./fenrir -t https://target # vuln_db.json in release
Repository → MIT Go | CLI
leviathan-core
Risk Kernel

Risk scoring you can audit. Computes from CVSS vectors, EPSS probability and CISA KEV presence rather than a vendor's black box, so the ranking has a reason. Needs requests and PyYAML.

$ pip install git+https://github.com/leviathan-offsec/leviathan-core.git
Repository → MIT Python | Kernel

03 // Pipeline

Pipes into what you already run.

surfacediff and HostageLVX take stdin and write stdout. They sit between tools you already have. 

# 1. Enumerate and snapshot subdomains with automated delta detection
$ subfinder -d example.com -silent | surfacediff snap -l subs --source subfinder
$ surfacediff diff -l subs || echo "New subdomains found!"

# 2. Pipe live subdomains straight into the takeover engine
$ cat subs.txt | hostage -threads 50 -verify

# 3. Snapshot web service changes (status flips, title changes, new tech)
$ httpx -l subs.txt -json -silent | surfacediff snap -l web --source httpx
$ surfacediff diff -l web --json > /tmp/surface_delta.json
