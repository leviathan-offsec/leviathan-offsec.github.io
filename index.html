01 // The Arsenal

Four tools. MIT licensed.

These run on hardware you already own. When we do an assessment, we run these same binaries, so you can check our work against the source.

HostageLVX
Takeover Engine

High-speed dangling DNS and subdomain takeover engine in Go. Native CNAME verification across 30+ cloud and edge providers, including signature-free fingerprinting of S3, Azure, GCP, Fastly, and legacy shared-hosting footguns.

$ go install github.com/leviathan-offsec/HostageLVX@latest
Repository → MIT Go | CLI
surfacediff
Surface Diffing

Immutable, content-addressed snapshotting and field-by-field diffing for external perimeters. Pipe in any recon output; exits 1 on a detected attack surface delta, so it drops straight into cron and CI without a wrapper.

$ pip install git+https://github.com/leviathan-offsec/surfacediff.git
Repository → MIT Python | stdlib only
FenrirLVX
CMS Auditor

Low-footprint Go CLI for WordPress and CMS auditing: plugin fingerprinting, offline vulnerability correlation, and Shodan queries. Every verdict reports how much of the target the local database could actually speak to, so a clean result is never confused with a stale one.

$ ./fenrir -t https://target # vuln_db.json in release
Repository → MIT Go | CLI
leviathan-core
Risk Kernel

Audited, contract-enforced vulnerability risk scoring kernel. Replaces black-box vendor scores with explainable formulas computed against CVSS vectors, EPSS probability and CISA KEV presence, so you can see why something ranked where it did.

$ git clone https://github.com/leviathan-offsec/leviathan-core.git
Repository → MIT Python | Kernel

03 // Unix Composability

It reads stdin and writes stdout.

Nothing to install but a Go binary. surfacediff and HostageLVX sit between the recon tools you already have, in your terminal or your cron job. 

# 1. Enumerate and snapshot subdomains with automated delta detection
$ subfinder -d example.com -silent | surfacediff snap -l subs --source subfinder
$ surfacediff diff -l subs || echo "New subdomains found!"

# 2. Pipe live subdomains straight into the takeover engine
$ cat subs.txt | hostage -threads 50 -verify

# 3. Snapshot web service changes (status flips, title changes, new tech)
$ httpx -l subs.txt -json -silent | surfacediff snap -l web --source httpx
$ surfacediff diff -l web --json > /tmp/surface_delta.json
