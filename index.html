02 // Unix Composability

Piped Attack Surface Monitoring

No proprietary daemons. Combine standard recon binaries with surfacediff and HostageLVX directly in your terminal or cron pipeline:

# 1. Enumerate and snapshot subdomains with automated delta detection subfinder -d example.com -silent | surfacediff snap -l subs --source subfinder surfacediff diff -l subs || echo "New subdomains found!" # 2. Pipe live subdomains directly into the takeover engine cat subs.txt | hostage -threads 50 -verify # 3. Snapshot web service changes (status code flips, title changes, new tech) httpx -l subs.txt -json -silent | surfacediff snap -l web --source httpx surfacediff diff -l web --json > /tmp/surface_delta.json
